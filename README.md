# Practice 26

A simple static website built with a component-based CSS structure and webpack for local development.

## Scripts

- `npm start` — run the development server
- `npm run build` — build the production bundle

## Project structure

- `index.html` — main page
- `css/` — base, layout, and component styles
- `js/` — front-end scripts
- `webpack.*.js` — webpack configuration
